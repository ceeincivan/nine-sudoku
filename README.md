# NINE

Solo or two phones. Dark UI. Colourful digits. Now with extra bounce, bigger reactions, and louder quacks.

## Web

```bash
npm install
npm run dev
```

## What's new (fun edition)

- Bouncier number placements and conflict shakes
- Reaction bursts that actually float with personality
- More reaction emojis (including the sacred 🦆)
- Snappier keypad + remaining-count badges
- Gloats that pop harder and hit harder
- Extra spicy taunts

## Cheat (local only)

On the home screen, long-press **NINE**, then swipe the mark. Cheat controls only exist on that device.
